# ตั้งค่าอีเมลบริษัทสำหรับส่งเลขยืนยัน (SMTP)

> คู่มือนี้เขียนให้คนที่ไม่ใช่นักพัฒนาทำตามได้เอง ใช้เวลาประมาณ 15 นาที
> ทำครั้งเดียวจบ ไม่ต้องทำซ้ำอีก

## ทำไมต้องตั้ง

ระบบส่งอีเมลอยู่ 2 จุดที่ผู้ใช้เจอจริง

- **ดูรหัสผ่านของตัวเอง** — ตัวแทนกดปุ่ม "ดูรหัสผ่าน" ระบบส่งเลข 6 หลักไปที่อีเมลของเขา เอาเลขมากรอกถึงจะเห็น
- **ลืมรหัสผ่าน** — กรอกอีเมลที่หน้าเข้าระบบ แล้วเอาเลข 6 หลักจากอีเมลมากรอกตั้งรหัสใหม่

ตอนนี้ทั้งสองจุดใช้ **อีเมลสำรองของ Supabase** ซึ่งมีข้อจำกัดสองอย่างที่ใช้งานจริงไม่ได้

1. ส่งได้ไม่กี่ฉบับต่อชั่วโมง เกินแล้วเงียบ — ตัวแทนหลายรายพร้อมกันจะมีคนไม่ได้รับ
2. ผู้ส่งเป็นชื่อของ Supabase ไม่ใช่ชื่อบริษัท ลูกค้าเห็นแล้วนึกว่าอีเมลหลอกลวง

ตั้งค่านี้แล้ว อีเมลจะออกจากบัญชี Gmail ของบริษัทเอง ส่งได้วันละ ~500 ฉบับ

---

## ขั้นที่ 1 — สร้าง "รหัสแอป" ของ Gmail

รหัสแอปคือรหัสผ่านชุดพิเศษ 16 ตัวอักษร ที่ให้โปรแกรมอื่นส่งอีเมลแทนเราได้
**ไม่ใช่รหัสผ่าน Gmail ปกติ** และยกเลิกทีหลังได้โดยไม่กระทบรหัสผ่านจริง

1. เปิด https://myaccount.google.com/security ด้วยบัญชี Gmail ที่จะใช้ส่ง
2. หัวข้อ **"การยืนยันแบบ 2 ขั้นตอน" (2-Step Verification)** ต้องเป็น **เปิด**
   ถ้ายังปิดอยู่ ให้เปิดก่อน (Google บังคับ — ไม่เปิดจะไม่มีเมนูรหัสแอปให้เลือก)
3. เปิด https://myaccount.google.com/apppasswords
4. ช่อง **App name** พิมพ์ `Benjamin PMS` แล้วกด **Create**
5. จะได้รหัส 16 ตัวอักษรแบบ `abcd efgh ijkl mnop` — **คัดลอกเก็บไว้**
   หน้านี้แสดงครั้งเดียว ปิดแล้วดูย้อนหลังไม่ได้ (ถ้าหายให้สร้างใหม่ ของเก่าลบทิ้ง)

> เวลานำไปกรอก **ให้ลบช่องว่างออกทั้งหมด** → `abcdefghijklmnop`

## ขั้นที่ 2 — กรอกในหน้าจัดการ Supabase

1. เปิด https://supabase.com/dashboard แล้วเลือกโปรเจกต์ **pms** (รหัส `yhhhcrvhkforwsagojho`)
   ⚠️ ต้องเป็น `pms` เท่านั้น — เป็นฐานข้อมูลของจริง
2. เมนูซ้าย **Authentication** → **Emails** → แท็บ **SMTP Settings**
3. เปิดสวิตช์ **Enable Custom SMTP** แล้วกรอกตามนี้

| ช่อง | กรอกว่า |
|---|---|
| Sender email | อีเมล Gmail ที่ใช้ส่ง (ต้องเป็นตัวเดียวกับข้อ Username) |
| Sender name | `Benjamin PMS` |
| Host | `smtp.gmail.com` |
| Port number | `465` |
| Minimum interval between emails | `60` (วินาที) |
| Username | อีเมล Gmail เต็ม ๆ เช่น `xxxx@gmail.com` |
| Password | รหัสแอป 16 ตัวจากขั้นที่ 1 (ลบช่องว่างแล้ว) |

4. กด **Save**

> **Sender email ต้องตรงกับ Username** — Gmail ไม่ยอมให้ส่งในนามอีเมลอื่น
> ถ้ากรอกไม่ตรง อีเมลจะถูกเปลี่ยนผู้ส่งกลับเป็นบัญชีจริงหรือส่งไม่ออกเลย

## ขั้นที่ 3 — ใส่ข้อความอีเมลให้มี "เลข 6 หลัก"

สำคัญที่สุดของทั้งคู่มือ ถ้าข้ามขั้นนี้ ผู้ใช้จะได้อีเมลที่มีแต่ลิงก์ ไม่มีเลขให้กรอก
(เคยเจอมาแล้ว — บอสแจ้ง 1 ก.ย. 69 ว่า "ไม่มีอะไรส่งมาในอีเมลเลย")

ที่ **Authentication** → **Emails** → แท็บ **Templates** มีแบบฟอร์มอีเมลหลายชนิด
ต้องแก้ **2 อัน** คือ **Magic Link** (ใช้ตอนดูรหัสผ่าน) และ **Reset Password** (ใช้ตอนลืมรหัสผ่าน)

แต่ละอันให้ลบของเดิมทิ้งทั้งหมด แล้ววางข้อความนี้แทน

### Magic Link — ใช้ตอนกด "ดูรหัสผ่าน"

Subject:
```
รหัสยืนยันสำหรับดูรหัสผ่าน — Benjamin PMS
```

Message body:
```html
<h2>รหัสยืนยันของคุณ</h2>
<p>นำเลขชุดนี้ไปกรอกในหน้าบัญชีของฉัน เพื่อดูรหัสผ่านของคุณ</p>
<p style="font-size:28px;font-weight:700;letter-spacing:6px">{{ .Token }}</p>
<p>เลขนี้ใช้ได้ครั้งเดียว ภายใน 1 ชั่วโมง</p>
<p style="color:#888;font-size:12px">ถ้าคุณไม่ได้เป็นคนขอ ไม่ต้องทำอะไร และแจ้งสำนักงานใหญ่ทันที</p>
```

### Reset Password — ใช้ตอนกด "ลืมรหัสผ่าน"

Subject:
```
รหัสยืนยันสำหรับตั้งรหัสผ่านใหม่ — Benjamin PMS
```

Message body:
```html
<h2>ตั้งรหัสผ่านใหม่</h2>
<p>นำเลขชุดนี้ไปกรอกที่หน้าเข้าสู่ระบบ เพื่อตั้งรหัสผ่านใหม่</p>
<p style="font-size:28px;font-weight:700;letter-spacing:6px">{{ .Token }}</p>
<p>เลขนี้ใช้ได้ครั้งเดียว ภายใน 1 ชั่วโมง</p>
<p style="color:#888;font-size:12px">ถ้าคุณไม่ได้เป็นคนขอ ไม่ต้องทำอะไร รหัสผ่านเดิมยังใช้ได้ตามปกติ</p>
```

กด **Save** ทีละอัน

> `{{ .Token }}` คือช่องที่ระบบจะแทนด้วยเลข 6 หลักจริงตอนส่ง — พิมพ์ให้ตรงเป๊ะทั้งวงเล็บและจุด
> ห้ามใช้ `{{ .ConfirmationURL }}` เป็นตัวหลัก เพราะนั่นคือ "ลิงก์" ซึ่งระบบเราไม่ได้ใช้แล้ว

## ขั้นที่ 4 — ทดสอบว่าใช้ได้จริง

1. เปิด https://benjamin-dealer.vercel.app/login
2. กรอกอีเมลของบัญชีตัวเอง แล้วกด **ลืมรหัสผ่าน?**
3. เปิดกล่องจดหมาย — ต้องได้อีเมลจากชื่อ **Benjamin PMS** ภายใน 1 นาที และ **เห็นเลข 6 หลัก**
4. เอาเลขมากรอกในช่องที่ขึ้นบนหน้าเดิม ตั้งรหัสใหม่ แล้วลองเข้าระบบ

ถ้าอีเมลไม่มา ให้ดูที่ **Authentication → Logs** ในหน้าจัดการ Supabase จะบอกสาเหตุตรง ๆ

| ข้อความที่เจอ | แปลว่า | แก้ยังไง |
|---|---|---|
| `535 Username and Password not accepted` | รหัสแอปผิด หรือเผลอใส่รหัสผ่าน Gmail ปกติ | สร้างรหัสแอปใหม่ กรอกแบบไม่มีช่องว่าง |
| `Sender address rejected` | Sender email ไม่ตรงกับ Username | แก้ให้เป็นอีเมลเดียวกัน |
| `connection timeout` | พอร์ตถูกบล็อก | เปลี่ยน Port เป็น `587` แล้ว Save ใหม่ |
| อีเมลมาแต่ไม่มีเลข มีแต่ลิงก์ | ยังไม่ได้แก้ Template | กลับไปทำขั้นที่ 3 |

## ข้อควรรู้

- รหัสแอปนี้ **ส่งอีเมลได้อย่างเดียว** อ่านเมล/เข้าบัญชีไม่ได้ และยกเลิกได้ทุกเมื่อที่หน้าเดิม
- Gmail ธรรมดาส่งได้ประมาณ **500 ฉบับ/วัน** — พอสำหรับตัวแทนหลักร้อยราย
  ถ้าอนาคตส่งมากกว่านั้น ค่อยย้ายไปใช้บริการส่งอีเมลอย่าง Resend/SendGrid (เปลี่ยนแค่ 4 ช่องในขั้นที่ 2)
- ถ้าเปลี่ยนรหัสผ่าน Gmail หรือปิดการยืนยัน 2 ขั้นตอน รหัสแอปจะใช้ไม่ได้ทันที ต้องสร้างใหม่
