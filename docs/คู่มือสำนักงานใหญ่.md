## 1. บทบาทผู้ใช้ในระบบ

| บทบาท | ทำอะไรได้ |
|---|---|
| **ผู้ดูแลระบบ** (SUPER_ADMIN) | ทุกอย่าง — จัดการตัวแทน · ผู้ใช้ · ราคากลาง · ตั้งค่าทั้งระบบ |
| **ผู้บริหาร HQ** (HQ_MANAGEMENT) | ดูข้อมูลทั้งเครือ + จัดการตัวแทนและตั้งค่าองค์กร |
| **เจ้าหน้าที่ HQ** (HQ_STAFF) | ดูข้อมูลทั้งเครือได้ แต่เข้าหน้าจัดการ (ตัวแทน/ผู้ใช้/ตั้งค่า) ไม่ได้ |

> สำนักงานใหญ่เห็นข้อมูลทุกสาขา · ตัวแทนเห็นเฉพาะของตัวเอง — แยกขาดที่ระดับฐานข้อมูล ไม่ใช่แค่ซ่อนบนหน้าจอ

## 2. เปิดสาขาใหม่ (งานที่ทำบ่อยที่สุด)

**ตัวแทนจำหน่าย → + เพิ่มตัวแทน**

1. กรอก **รหัสตัวแทน** (3 ตัวอักษร เช่น CNX) และ **ชื่อตัวแทน**
2. เลือก **ภาค** ก่อน แล้วค่อยเลือก **จังหวัด** (รายการจังหวัดจะกรองตามภาคให้เอง)
3. ใส่ **เป้ายอดขายรายปี** — ระบบเสนอค่าเริ่มต้นตามภาคให้ แก้ได้
4. กด **สร้างตัวแทน** → ระบบสร้างบัญชีเข้าระบบให้อัตโนมัติ แล้วแสดงอีเมลกับรหัสผ่าน

> **คัดลอกรหัสผ่านตอนนั้นเลย** แล้วส่งให้ตัวแทนทางช่องทางที่ปลอดภัย
> ถ้าปิดหน้าต่างไปแล้ว ยังเปิดดูย้อนหลังได้ (ดูข้อ 3)

## 3. ดูรหัสเข้าระบบ / รีเซ็ตรหัสผ่านให้ตัวแทน

**ตัวแทนจำหน่าย → กดปุ่มรูปกราฟของสาขานั้น → แท็บภาพรวม → การ์ด "ข้อมูลเข้าระบบของตัวแทน"**

- **ดูรหัสผ่าน** — กดปุ่มดูรหัสผ่าน ระบบจะดึงมาแสดงพร้อมบอกว่าตั้งเมื่อไหร่โดยใคร
- **รีเซ็ตรหัสผ่าน** — ออกรหัสใหม่ทันที รหัสเดิมใช้ไม่ได้ทันที ต้องแจ้งรหัสใหม่ให้ตัวแทน

> ทุกครั้งที่มีคนเปิดดูรหัสของสาขาไหน ระบบบันทึกไว้หมด (ดูที่ **บันทึกการใช้งาน**)

**ปุ่ม "เข้าระบบ" ในตาราง** — เข้าไปดูหน้าจอในมุมมองของตัวแทนรายนั้น ใช้ตอนช่วยแก้ปัญหาให้เขาทางโทรศัพท์

---

## 4. ราคากลางของแม่แบบอาคาร

**แคตตาล็อกแม่แบบ**

- ตั้งราคากลางต่อตารางเมตรของแต่ละแม่แบบ และแยกย่อยตามแม่แบบย่อยได้
- ราคานี้เป็น**ตัวตั้งต้น**ของทุกใบเสนอราคาทั้งเครือ — ตัวแทนปรับได้ตามการเจรจา แต่เริ่มจากค่านี้

> ⚠️ ผิดตรงนี้ = ผิดทุกใบเสนอราคาทั้งเครือ ตรวจให้ดีก่อนบันทึก

---

## 5. ตั้งค่าระดับองค์กร

**ตั้งค่า** — มี 5 แท็บ กดปุ่ม **บันทึก** มุมขวาบนทุกครั้งหลังแก้

| แท็บ | ใช้ทำอะไร |
|---|---|
| **บริษัท** | ข้อมูลบริษัทเบนจามิน — ใช้อ้างอิงในเอกสารและระบบ |
| **ผู้ใช้งานและสิทธิ์** | เพิ่ม/แก้/ปิดบัญชีผู้ใช้ฝั่งสำนักงานใหญ่ · ดูตารางสิทธิ์ของแต่ละบทบาท |
| **เส้นทางการขาย** | งานมาตรฐานของแต่ละขั้น (เพิ่ม/ลบ/แก้ชื่อได้ — ตัวแทนเช็กงานชุดนี้แล้วสถานะเลื่อนขั้นเอง) · รายการเหตุผลที่ปิดการขายไม่สำเร็จ (ตัวแทนเลือกจากรายการนี้) |
| **เป้าหมายยอดขาย** | เป้ารวมทั้งปีของทั้งเครือ · อัตราปิดการขายเป้าหมาย |
| **การแจ้งเตือน** | เปิด/ปิดกฎเตือน 6 ข้อ และตั้งเกณฑ์วัน เช่น ลูกค้าเป้าหมายเงียบกี่วันถึงเตือน |

## 6. หน้าดูข้อมูลทั้งเครือ

| เมนู | ดูอะไร |
|---|---|
| **แดชบอร์ดสำนักงานใหญ่** | ยอดขายรวมเทียบเป้า · อันดับตัวแทน · แนวโน้มรายเดือน |
| **ภาพรวมยอดขาย** | เทียบผลงานตัวแทนแต่ละราย — ลูกค้าเป้าหมาย/ใบเสนอราคา/ยอดขาย/อัตราปิด/เทียบเป้า |
| **ลูกค้าเป้าหมายทั้งเครือ** | ลูกค้าเป้าหมายทุกสาขา กรองตามตัวแทน/ภาค/จังหวัด/สถานะ |
| **ใบเสนอราคาทั้งเครือ** | ใบทุกสาขา พร้อมสถิติอัตราปิดการขายและเหตุผลที่เสียงาน |
| **ลูกค้าทั้งเครือ** | ลูกค้าที่ปิดการขายได้แล้วทุกสาขา พร้อมประวัติการซื้อ |
| **บันทึกการใช้งาน** | ใครทำอะไรเมื่อไหร่ — ใช้ตรวจสอบย้อนหลัง |

ทุกหน้ามีปุ่ม **ส่งออก** สำหรับดึงข้อมูลเป็นไฟล์ไปทำรายงานต่อ

## 7. งานดูแลระบบ (ทำเป็นรอบ)

| งาน | ความถี่ | วิธีทำ |
|---|---|---|
| ตรวจว่าข้อมูลสำรองยังทำงาน | สัปดาห์ละครั้ง | เปิดไฟล์ `backups\backup-daily.log` ดูว่าบรรทัดล่าสุดขึ้น `[OK]` |
| ตรวจความพร้อมระบบ | เดือนละครั้ง | `npm run preflight` |
| ซ้อมกู้คืนข้อมูล | ทุก 3 เดือน | `npm run backup:drill` (ไม่แตะข้อมูลจริง) |
| ดูบันทึกการใช้งาน | ตามต้องการ | เมนูบันทึกการใช้งาน |

> การสำรองข้อมูลอัตโนมัติทำงานทุกวัน **02:00 น.** เฉพาะตอนเครื่องที่ตั้งไว้เปิดอยู่

## 8. ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| ตัวแทนบอกว่าเข้าระบบไม่ได้ | เข้าหน้ารายละเอียดสาขานั้น กด "ดูรหัสผ่าน" เทียบกับที่เขาใช้ · ถ้าไม่ตรงให้กด "รีเซ็ตรหัสผ่าน" แล้วแจ้งรหัสใหม่ |
| ตัวแทนบอกว่าใบเสนอราคาไม่มีหัวกระดาษ | เขายังไม่ได้กรอกข้อมูลบริษัทของสาขา — ให้เข้า ตั้งค่า › บัญชีดีลเลอร์ แล้วกรอกให้ครบ |
| ยอดขายบนแดชบอร์ดไม่ตรงกับที่คิด | ตรวจตัวกรองช่วงเวลามุมขวาบนก่อน — ทุกหน้าคิดตามช่วงที่เลือก |
| หน้าจอขึ้น "เกิดข้อผิดพลาดในหน้านี้" | กด "ลองใหม่" หนึ่งครั้ง · ถ้ายังเป็นให้กด Ctrl+Shift+R · ยังไม่หายให้แจ้งผู้ดูแลระบบพร้อมบอกว่าอยู่หน้าไหน |
| เพิ่มตัวแทนแล้วขึ้นว่ารหัสซ้ำ | รหัสสาขาต้องไม่ซ้ำกับที่มีอยู่ ใช้รหัสอื่นแทน |

## 9. ขอบเขตของระบบ (สิ่งที่ระบบนี้ไม่ทำ)

ระบบนี้ดูแล **งานขายอย่างเดียว** — ตั้งแต่ลูกค้าเป้าหมายจนปิดการขาย

ไม่มีและไม่ได้ออกแบบให้มี: งานก่อสร้าง · การผลิต · การติดตั้ง · งานวิศวกรรม · การซ่อมบำรุง
