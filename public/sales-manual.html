1 รับผู้สนใจใหม่ เมนู: ผู้สนใจ

เป้าหมาย: บันทึกผู้ที่ติดต่อเข้ามาให้เป็น “ผู้สนใจ” พร้อมระบุแม่แบบที่สนใจและมูลค่าประเมิน
  1. ไปที่เมนู ผู้สนใจ แล้วกดปุ่ม + เพิ่มผู้สนใจ (มุมขวาบน)
  2. กรอกข้อมูลในฟอร์ม “เพิ่มผู้สนใจใหม่”: บริษัท* ผู้ติดต่อ* โทรศัพท์ จังหวัด
  3. เลือก แม่แบบที่สนใจ — รายการดึงจากแคตตาล็อก “แม่แบบ” (โกดังสำเร็จรูป / โรงงาน / อาคารสำเร็จรูปทุกประเภท / งานตามแบบของลูกค้า / งานรีโนเวท / สนามกีฬาในร่ม)
  4. ใส่ มูลค่าประเมิน, เลือก ผู้รับผิดชอบ และ แหล่งที่มา แล้วกด บันทึก
ผลลัพธ์: ผู้สนใจใหม่แสดงบนสุดของตาราง สถานะเริ่มต้น “ผู้สนใจใหม่” ทันที

2 ติดตามและเปลี่ยนขั้นตอน เมนู: ผู้สนใจ

เป้าหมาย: เดินผู้สนใจไปตามเส้นทางการขาย ผู้สนใจใหม่ → ติดต่อแล้ว → รวบรวมความต้องการ → เสนอราคา → เจรจา
  1. คลิกแถวผู้สนใจเพื่อเปิดหน้ารายละเอียด หรือใช้ มุมมองคัมบัง (ปุ่มสลับมุมมอง มุมขวา)
  2. เปลี่ยนสถานะได้ 2 วิธี: กดป้ายสถานะในตารางแล้วเลือกขั้นถัดไป หรือ ลากการ์ดข้ามคอลัมน์ในมุมมองคัมบัง
  3. แถบสรุปด้านบนบอกจำนวนผู้สนใจแต่ละขั้น และมูลค่ารวม กดเพื่อกรองดูเฉพาะขั้นนั้นได้
ผลลัพธ์: สถานะอัปเดตทันทีและคงอยู่ข้ามหน้า

3 เปิดเป็นโอกาสการขาย (ดีล) ผู้สนใจ → เส้นทางการขาย

เป้าหมาย: ยกผู้สนใจที่มีแนวโน้มปิดได้ ขึ้นเป็นดีลในกระดานเส้นทางการขาย
  1. เปิดรายละเอียดผู้สนใจ → ที่แถบปุ่มด้านขวา กด ⚡ เปิดเป็นดีล
  2. ระบบสร้างดีลในเมนู เส้นทางการขาย โดยผูกกับผู้สนใจเดิม (กันสร้างซ้ำ) และพาไปที่หน้ากระดานอัตโนมัติ
ผลลัพธ์: มีการ์ดดีลใหม่บนกระดาน พร้อมมูลค่าและผู้รับผิดชอบที่ดึงมาจากผู้สนใจ

4 ออกใบเสนอราคา ผู้สนใจ / เมนู: ใบเสนอราคา

เป้าหมาย: จัดทำใบเสนอราคาในนามบริษัทของสาขา แล้วส่งให้ลูกค้า
  1. วิธีที่ 1 (แนะนำ): ในรายละเอียดผู้สนใจ กด สร้างใบเสนอราคา ระบบจะเติมชื่อลูกค้าและมูลค่าให้อัตโนมัติ
  2. วิธีที่ 2: ไปเมนู ใบเสนอราคา กด + เพิ่มใบเสนอราคา แล้วเลือกลูกค้า/แม่แบบ/พื้นที่/มูลค่า
  3. ใบเสนอราคาที่สร้างจะมีสถานะ “ร่าง” — ตรวจความถูกต้องแล้วกด ส่งลูกค้า เพื่อเปลี่ยนเป็น “ส่งแล้ว”
  4. พิมพ์เอกสาร: เปิดใบเสนอราคา → กด พิมพ์ / ดาวน์โหลด PDF (เอกสารออกในนามบริษัทของสาขา พร้อมเลขผู้เสียภาษี/ตราประทับ/ลายเซ็นจากหน้า “ตั้งค่า”)
เคล็ดลับ: ตั้งค่าโลโก้ · เลขผู้เสียภาษี · ตราประทับ · ลายเซ็น ล่วงหน้าที่เมนู ตั้งค่า → โปรไฟล์บริษัท / ตั้งค่าใบเสนอราคา เพื่อให้เอกสารสมบูรณ์ทันทีที่พิมพ์

5 ปิดการขาย เมนู: เส้นทางการขาย

เป้าหมาย: บันทึกผลการขายเมื่อได้งาน (หรือไม่ได้งาน)
  1. ไปเมนู เส้นทางการขาย เปิดการ์ดดีลที่ลูกค้าตอบรับแล้ว
  2. ที่แถบปุ่มด้านขวา กด ปิดการขายนี้ → แล้วเลือก ✅ ปิดการขายสำเร็จ
  3. หากไม่ได้งาน เลือก ❌ ปิดการขายไม่สำเร็จ และระบุเหตุผล
ผลลัพธ์เมื่อ ปิดการขายสำเร็จ ระบบทำให้อัตโนมัติในคราวเดียว:
• ดีล = ปิดการขายสำเร็จ · ผู้สนใจ = ปิดการขาย (ได้งาน)
• สร้างลูกค้าใหม่ ให้อัตโนมัติ · ใบเสนอราคาที่เกี่ยวข้องเปลี่ยนเป็น “ตอบรับ”

6 ตรวจสอบลูกค้าที่ได้ เมนู: ลูกค้า

เป้าหมาย: ยืนยันว่าผู้สนใจกลายเป็นลูกค้าเรียบร้อย และดูประวัติการขาย
  1. ไปเมนู ลูกค้า จะพบลูกค้ารายใหม่แสดงอยู่ สถานะ “ใช้งานอยู่”
  2. ลูกค้าที่มีใบเสนอราคาปิดการขายแล้วจะถูกจัดเป็น “ลูกค้าเดิม” โดยอัตโนมัติ
  3. กด ดู → หรือ “หน้าเต็ม” เพื่อดูรายละเอียด: ใบเสนอราคา · นัดหมาย · ไทม์ไลน์กิจกรรม
ครบวงจร: ผู้สนใจ → ดีล → ใบเสนอราคา → ปิดการขาย → ลูกค้า ข้อมูลไหลต่อเนื่องทุกหน้า

✓ สรุปเส้นทางแบบย่อ

  1. ผู้สนใจ → + เพิ่มผู้สนใจ (เลือกแม่แบบที่สนใจ)
  2. ผู้สนใจ → เปลี่ยนขั้นตอน / ลากคัมบัง
  3. ผู้สนใจ → ⚡ เปิดเป็นดีล
  4. ผู้สนใจ/ใบเสนอราคา → สร้างใบเสนอราคา → ส่งลูกค้า → พิมพ์ PDF
  5. เส้นทางการขาย → ปิดการขายนี้ → ✅ ปิดการขายสำเร็จ
  6. ลูกค้า → ตรวจลูกค้าใหม่ (สร้างอัตโนมัติ)
หมายเหตุ: ระบบเวอร์ชันปัจจุบันเป็นการสาธิต (ข้อมูลจำลอง) — ข้อมูลจะรีเซ็ตเมื่อรีเฟรชหน้า · ราคากลาง/แม่แบบกำหนดโดยสำนักงานใหญ่ ตัวแทนจำหน่ายดูได้อย่างเดียว
