# /scenario — ทดสอบระบบแบบ scenario (ผู้ใช้จริงจะทำอะไรบ้าง)

โฟกัส: **$ARGUMENTS** (ถ้าไม่ระบุ = ตรวจทั้งระบบ)

หลักการ: **ตรวจแค่โค้ดไม่พอ** — ต้องขับเบราว์เซอร์จริงดูว่าผู้ใช้จะเจออะไร. ทำงานหลาย persona พร้อมกัน แต่ละ persona มองคนละมุม.

## ขั้นตอน

1. **เช็คเซิร์ฟเวอร์**: dev server ต้องรันที่ `http://localhost:3000`
   (ถ้าไม่ขึ้น → บอกผู้ใช้ให้ `npm run dev` ก่อน · ห้ามรัน `next build` ตอน turbopack ทำงาน)

2. **รัน Playwright harness** (3 persona พร้อมกัน — workers:3):
   ```
   npm run scenario
   ```
   สเปกอยู่ที่ `tests/scenario/` แยกตาม persona:
   - `user.spec.ts` — ผู้ใช้จริง: เปิดทุกหน้า (HQ+Dealer) + edge (404, ค้นหาไม่เจอ) ต้องไม่พัง
   - `ux.spec.ts` — UX expert: เมนูไปได้ทุกลิงก์ · เตือน unsaved · การแจ้งเตือนแยก role · empty state
   - `ui.spec.ts` — UI expert: ไม่มี horizontal scroll · responsive 768px · มีหัวข้อหน้า
   สลับ role ผ่าน `helpers.ts` (`open(page, "hq"|"dealer", path)`)

3. **ถ้าโฟกัสฟีเจอร์ใหม่ที่ยังไม่มีสเปก** → เขียนสเปกเพิ่มใน `tests/scenario/` ตามรูปแบบเดิม (use-case ปกติ + edge-case) แล้วรันใหม่

4. **สำรวจเชิงลึก (optional, เมื่อ scenario ซับซ้อน)** — spawn subagent 3 ตัวพร้อมกัน (Agent tool, single message) โดยกำหนด role/persona ชัด:
   - **UI expert**: "คุณคือผู้เชี่ยวชาญ UI ตรวจ layout/สี/ระยะ/responsive/องค์ประกอบซ้อนทับ ที่ localhost:3000 ทั้ง HQ และ Dealer รายงานจุดที่ผู้ใช้จะสะดุดตา"
   - **UX expert**: "คุณคือผู้เชี่ยวชาญ UX ตรวจ flow/ความสับสน/การเตือน/สถานะว่าง/ความสม่ำเสมอของคำ ระหว่างทำงานจริง รายงานจุดที่ผู้ใช้จะงงหรือทำพลาด"
   - **user (ผู้ใช้ทั่วไป)**: "คุณคือเซลส์/ผู้บริหารที่ใช้งานจริง ลองทำงานให้จบ (สร้างลีด→ใบเสนอราคา→ปิดการขาย / HQ คุมนโยบาย) รายงานสิ่งที่ทำไม่ได้หรือติดขัด"
   ให้แต่ละ agent ขับเบราว์เซอร์ด้วย Playwright (เขียน .ts ชั่วคราวใน `tests/scenario/` แล้ว `npx playwright test <file>`) — ไม่ใช่แค่อ่านโค้ด

5. **สรุปผล**: จำนวน pass/fail + **บั๊ก/ปัญหา UX/UI จริงที่เจอ** (พร้อม use-case ที่ทำให้เกิด) เรียงตามความรุนแรง · ไม่ต้องแก้เว้นแต่ผู้ใช้สั่ง

## เกณฑ์
- แต่ละ persona = มุมมองต่างกัน (อย่ารวมเป็นมุมเดียว)
- ทุกเทสต์ต้อง deterministic (mock วันนี้ = 2026-06-30) · หลีกเลี่ยง selector เปราะ (ใช้ role/aria-label/text)
- รายงานเฉพาะสิ่งที่ **ยืนยันจากเบราว์เซอร์จริง** ไม่ใช่เดาจากโค้ด
